\# Sangam



A collaborative workspace for projects, workflows, and AI-powered intelligence.



\## Vision



Sangam aims to bring people, projects, tasks, workflows, and organizational knowledge together in one connected platform.



\## Goals



\- Manage organizations, teams, projects, and tasks.

\- Provide secure authentication and authorization.

\- Support collaboration and project discussions.

\- Integrate AI-assisted search and organizational knowledge.

\- Build reliable, testable, and maintainable software.



\## Technology Stack



The technology stack will be introduced incrementally as the project develops.



\- Backend: Java 21 and Spring Boot

\- Database: PostgreSQL

\- Frontend: React and TypeScript

\- Version control: Git and GitHub

\- Testing: JUnit and other appropriate testing tools

\- Infrastructure: Docker and CI/CD



\## Project Structure



\- `backend/` — Backend application

\- `frontend/` — Frontend application

\- `infra/` — Infrastructure and deployment

\- `docs/` — Project documentation



\## Development Approach



Sangam is being developed incrementally, with an emphasis on understanding the underlying concepts, writing maintainable code, and testing changes before integrating them.
